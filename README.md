# 拾礼 · 小程序高保真原型

面向「礼品公司服务银行/企业客户」场景的双身份小程序：企业采购（B）与终端用户（C）在同一小程序内切换，支持中英双语。

## 怎么打开

双击 prototype/index.html 即可，无需安装、无需联网、无需本地服务器。

- 电脑看手机效果：Chrome 按 F12 → Ctrl+Shift+M → 选 iPhone 14 Pro（393 × 852）
- 左侧「屏幕目录」可直接跳到任意一屏
- 顶部身份标识可切换身份；连点三次显示调试信息

## 微信登录

不做登录页，三层递进，能不打扰就不打扰。

| 层 | 触发 | 结果 |
|---|---|---|
| 静默登录 | 打开小程序 | 拿到 openid，可浏览、可按零售价购买 |
| 手机号授权 | 兑换 / 下单 / 看权益 / 账号与安全 | 手机号 → 服务端比对 HR 白名单 |
| 采购申请 | 身份面板「申请采购权限」 | 企业管理员审批，1 个工作日内 |

- **员工**：手机号比对企业名单，识别后额度自动到账，零输入
- **采购**：必须审批，不能自助开通，审批期间仍是员工身份
- **个人**：默认身份，无需任何绑定
- **邀请码**：作为兜底入口，收在二级
- 拒绝授权不影响浏览，只是没有企业权益

原型可完整走通：个人 → 权益 → 授权手机号 → 识别中 → 已识别 → 开始使用（切到员工身份）。

## 悬浮 Dock

五个入口放在同一个悬浮胶囊里，五项样式完全一致，中间「选品」不加圆圈、不加底色。

| 身份 | 五格 |
|---|---|
| 员工 / 个人 | 首页 · 分类 · **选品** · 我的 |
| 采购 | 工作台 · 分类 · **选品** · 报价 · 我的 |

- 胶囊：左右内缩 16px，高 64，全圆角；半透明 + 背景模糊 + 0.5px 描边 + 柔光
- 选中态：只有当前所在的 Tab 转墨色，其余 42% 灰
- 详情页、兑换页自动收起 Dock，只留底部操作条
- 所有页面底部预留 104px

## 搜索

首页顶部是一条通栏胶囊形搜索栏，高度 46px、全圆角，放大镜落在弧线最右端。

- 点任意位置进入「全部礼品」，并自动聚焦输入框
- 「全部礼品」页可即时过滤：中文名、规格、编号，以及拼音与英文别名
- 例：搜「杯」得玻璃杯与保温杯；搜 titanium 得钛保温杯；搜 G-10293 得单个商品
- 无结果时显示空状态，并隐藏底部价格说明
- 分类页、全部礼品页共用同一套样式，视觉一致
- 中英文下占位文案、空状态文案自动切换

## 价格筛选

「全部礼品」页搜索栏下方是一行价格检索，和搜索栏用同一种胶囊框：一个圆角容器里放 最低 / 至 / 最高，右端是墨色搜索按钮。上方还有一排预算 chip，点一下立即生效。

首页保留了一排「您的预算」chip，只做快捷入口：点一下带着筛选跳到「全部礼品」，两边的选中状态同步。

- 只填一侧按单边筛，两侧都填按区间
- 最低大于最高会自动交换，不报错
- 与上面的预算 chip 互斥：点 chip 会把值填进输入框，输入自定义区间会取消 chip 选中
- 点预算 chip 立即筛选；输入自定义区间后点「搜索」或按回车生效
- 结果就地刷新，不再跳页
- 按参考价筛选
- 切换身份后会按新价格重算结果

## 专题卡（首页顶）

搜索栏下方是一张 4:3 的双面专题卡。

- 每 4 秒自动翻面；手指左右拖动跟手翻，点一下也能翻
- 拖动超过 22% 宽度或 0.4px/ms 即翻面，否则回弹；纵向滑动优先，不误触
- 手动操作后 10 秒内停止自动翻，避免抢注意力
- 底部两个点，可点击直达
- 正面「中秋礼盒」（暖米色），反面「企业定制」（冷灰绿）
- 翻面用 rotateY + perspective 1000px，550ms，与页面切换的 340ms 区分开
- 「查看 ›」跳转全部礼品，不触发翻面

## 分类

左侧品类栏 + 右侧商品，借用电商分类页的结构，换成纸感语言。

- 左栏 104px，底色比正文深一档（paper-3），与右侧自然分栏
- 选中项：墨色文字 + 左侧 2px 竖线；未选中为次文字色
- 右侧显示该品类商品，两列，卡片比「全部礼品」略小
- 5 个品类：杯壶 · 茶器 / 家居 · 香氛 / 礼盒 · 食礼 / 文具 · 办公 / 餐厨 · 器皿
- 品类状态保留：从商品详情返回时，仍停在原来那一格

## 品牌

品牌页是字母名录，目前**不在底部导航**里，只作为独立页面保留（可从左侧屏幕目录进入）。

- 27 个品牌，覆盖 15 个首字母
- 三列卡片，没有 logo，用品牌首字做衬线单字标记
- 右侧 A–Z 索引可点跳转，滚动时自动高亮当前分区
- 搜索同时匹配品牌名与拼音：搜 fei 能命中飞利浦、摩飞
- 点品牌 → 全部礼品，只显示该品牌商品，顶部出现「品牌 承月 ×」标签，点 × 清除
- 品牌下没有商品时进空状态

权益页没有删，从 Dock 撤下后改走「我的 → 权益明细」。

## 商品图册

商品详情页顶部是 4 张图，底部居中有页码点。

| 序号 | 内容 |
|---|---|
| 1 | 主图 |
| 2 | 细节（同一插画放大约 1.45 倍并裁切） |
| 3 | 尺寸（宽高标注，数字取自商品数据） |
| 4 | 场景（渐变底 + 落地投影） |

- 手指左右拖动时图片跟手，松手按 25% 位移吸附到上一张或下一张
- 点页码点直接跳转，不经过中间页
- 第一张不能右滑、最后一张不能左滑，边缘有阻尼
- 纵向滚动不受影响（track 设了 touch-action: pan-y）

第 3 张是给采购看的：参考图里那种 26CM / 38CM 标注，这里做成了每件商品的真实宽高。

## 价格

全站只显示一个价格：**参考价**（商城零售价）。

- 商品卡、详情、购买弹层、清单、价格筛选统一用它
- 不再按身份区分额度价 / 协议价 / 零售价

## 选品弹层

点「加入选品单」弹出底部半屏。

- 商品行：缩略图 + 名称 + 参考价 / 件
- 数量：− / 输入 / +，范围 1–999
- 合计按参考价 × 数量实时计算
- 点「加入选品单」写入清单，关闭弹层并提示
- 不含联系人、手机号、支付：本期不做线上交易

## 切换动效

像手机主页翻页：两页并排、同速平移、无叠加、无变暗。

| 动作 | 新页面 | 旧页面 |
|---|---|---|
| 首页 → 分类 | 从右侧 100% 进入 | 退到 -100% |
| 分类 → 首页 | 从左侧 -100% 进入 | 退到 100% |
| 进商品详情 | 从右侧进入 | 退到 -100% |
| 返回 | 从左侧进入 | 退到 100% |

- 两页位移相同、方向相反，全程首尾相接，不露白也不重叠
- 时长 340ms，曲线 cubic-bezier(.22,.61,.36,1)
- 每页带不透明纸色底，滑过即覆盖，不会透出另一页文字
- 方向由五个 Tab 的位置决定，不写死
- 连点会立即结束上一段动画再开始新的，不会叠层
- 支持 prefers-reduced-motion

### 性能

帧率由屏幕刷新率决定，CSS 没有「帧数」参数。这一版做了三件事保证跑满：

- 位移改用 translate3d，动画走 GPU 合成，不触发重排重绘
- 动画期间临时关闭 Dock 的背景模糊（backdrop-filter 每帧重算，最费）
- 动画期间禁用页面点击，避免快速连点造成的重复触发

本机实测（120Hz 屏）：

| 场景 | 帧率 | 最长帧间隔 |
|---|---|---|
| 静止 | 121 fps | 8.7 ms |
| 切换中 | 121 fps | 8.7 ms |

真机提示：微信小程序的 WebView 渲染器通常锁 60Hz，要用上 120Hz 需改用 Skyline 渲染器。

## 和参考小程序的主要差异

| 维度 | 参考 | 本方案 |
|---|---|---|
| 首屏 | 深蓝 Banner + 口号 | 纸底 + 大标题 + 权益卡 |
| 品类入口 | 十宫格图标 | 无宫格，编辑式纵向流 |
| 价格 | 红色粗体居中 | 近黑等宽数字左对齐 |
| 底部栏 | 实心 TabBar + 深蓝凸起圆钮 | 悬浮玻璃胶囊，五项一致 |
| 切换 | 无过渡 | 主页式翻页，两页同速 |
| 登录 | 账号密码 / 强制授权 | 静默登录，按需授权 |
| 身份 | 无 | 卡包式切换 + 预览态 |
| 语言 | 无 | 我的页右上角中英切换 |

## 已知限制

- 原型仍读 `data.js`，尚未改成调用接口

- 英文为原型级翻译，正式上线前需母语校对
- 没有支付、开票、物流
